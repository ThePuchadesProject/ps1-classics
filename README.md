# PS1 Classics

[English](#english) | [Español](#español)

## English

This is my first project learning and using React. I built a small retro store inspired by classic PlayStation 1 games to practice the basics of React, state management, and props.

Demo: [ps1classics.thepuchadesproject.com](https://ps1classics.thepuchadesproject.com)

### What the project does

- Shows a catalog of classic PS1 games with image, description, and price.
- Lets you add games to a shopping cart.
- You can increase, decrease, or remove items in the cart.
- Calculates the total price in euros.
- Saves the cart in `localStorage` so items stay there if you refresh the page.
- Retro PS1 style using custom CSS and the *Chakra Petch* font.

### Tech stack

- React
- Vite
- CSS
- JavaScript

### Next steps

Since this is a learning project, I plan to improve it over time:

- [x] Move the project from JavaScript to TypeScript.
- [x] Organize the logic better using custom hooks.
- [x] Migrate state management from useState to useReducer.
- [x] Add a search input.


### How to run it locally

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the project:
   ```bash
   npm run dev
   ```

## Español

Este es mi primer proyecto aprendiendo y usando React. He creado una pequeña tienda retro inspirada en juegos clásicos de PlayStation 1 para practicar los conceptos básicos de React, el estado y las props.

Demo: [ps1classics.thepuchadesproject.com](https://ps1classics.thepuchadesproject.com)

### Qué hace el proyecto

- Muestra un catálogo de juegos clásicos de PS1 con carátula, descripción y precio.
- Permite añadir juegos a un carrito de compra.
- Puedes sumar, restar o quitar juegos del carrito.
- Calcula el total a pagar en euros.
- Guarda los datos en `localStorage` para no perder el carrito al recargar la página.
- Estilo retro de PS1 con CSS propio y la fuente *Chakra Petch*.

### Tecnologías utilizadas

- React
- Vite
- CSS
- JavaScript

### Próximos pasos

Al ser un proyecto para aprender, tengo pensado ir mejorándolo con el tiempo:

- [x] Pasar el proyecto de JavaScript a TypeScript.
- [x] Ordenar mejor la lógica usando custom hooks.
- [x] Migrar la gestión del estado de useState a useReducer.
- [x] Añadir un buscador.
